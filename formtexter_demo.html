FormTexter Demo

Anleitung für Tests

Wie FormTexter funktioniert:

  • Das Plugin liest den Inhalt des Textfelds "Interessen" aus.
  • Kommagetrennte Begriffe werden einzelnen Checkboxen zugeordnet.
  • Beispiel: "Newsletter, Technik" → aktiviert Checkboxen "Newsletter abonnieren" und "Technik-Updates".

Testablauf:

  1. Stellen Sie sicher, dass das Plugin in Firefox geladen ist (about:debugging).
  2. Klicken Sie auf das FormTexter-Icon in der Firefox-Toolbar.
  3. Wählen Sie das Textfeld "Interessen" per Klick aus.
  4. Erstellen Sie Zuordnungen (z. B. "Newsletter" → Checkbox "Newsletter abonnieren").
  5. Geben Sie Text ein und prüfen Sie, ob die Checkboxen aktiviert werden.
